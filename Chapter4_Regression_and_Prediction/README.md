# Chapter 4 — Regression and Prediction

Reproduction of the code examples from *Practical Statistics for Data
Scientists* Chapter 4, with a theoretical explanation before/after every
code block.

## What's covered

| Section | Concepts | Dataset used |
|---|---|---|
| Simple Linear Regression | Least squares, fitted values, residuals | `LungDisease.csv` |
| Multiple Linear Regression | Predicting from several variables at once | `house_sales.csv` |
| Assessing the Model | RMSE, R², adjusted R² | `house_sales.csv` |
| Factor Variables | One-hot/dummy encoding of categories | `house_sales.csv` |
| Interpreting the Equation | Confounding variables, interaction effects | `house_sales.csv` |
| Regression Diagnostics | Cook's distance, heteroskedasticity, normality of residuals | `house_sales.csv` |

## Key takeaway

A regression coefficient's headline number is only meaningful alongside its
diagnostics. RMSE and R² tell you how *accurate* the predictions are;
residual plots, Cook's distance, and QQ-plots tell you whether the fitted
model can actually be *trusted* — a model can look good on R² alone and
still violate assumptions that make its coefficients or confidence
intervals misleading.
