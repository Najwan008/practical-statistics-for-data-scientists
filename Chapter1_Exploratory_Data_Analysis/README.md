# Chapter 1 — Exploratory Data Analysis

Reproduction of the code examples from *Practical Statistics for Data
Scientists* (2nd ed.) Chapter 1, with an added theoretical explanation
before/after every code block.

## What's covered

| Section | Concepts | Dataset used |
|---|---|---|
| Estimates of Location | mean, trimmed mean, median, weighted mean/median | `state.csv` |
| Estimates of Variability | std. deviation, robust MAD, IQR | `state.csv` |
| Percentiles & Boxplots | percentiles, five-number summary, boxplots | `state.csv` |
| Frequency Table & Histograms | binning, histogram shape / skew | `state.csv` |
| Density Estimates | Kernel Density Estimation (KDE) | `state.csv` |
| Binary & Categorical Data | bar charts | `dfw_airline.csv` |
| Correlation | Pearson correlation, correlation heatmap | `sp500_data.csv.gz`, `sp500_sectors.csv` |
| Scatterplots | pairwise relationships | `sp500_data.csv.gz` |
| Hexbin & Contour | 2D density for large N | `kc_tax.csv.gz` |
| Two Categorical Variables | cross-tabulation | `lc_loans.csv` |
| Categorical + Numeric | grouped boxplots | `airline_stats.csv` |
| Multiple Variables | facet grids | `kc_tax.csv.gz` |

## Key takeaway

The chapter's central theme: **pair a robust estimate with a non-robust one**
(mean vs. median, std. dev. vs. MAD) — the gap between them is itself a
diagnostic for skew and outliers, before any modeling begins. See the
notebook's summary table at the end for a full comparison.
