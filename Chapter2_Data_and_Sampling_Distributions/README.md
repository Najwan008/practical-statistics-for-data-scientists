# Chapter 2 — Data and Sampling Distributions

Reproduction of the code examples from *Practical Statistics for Data
Scientists* Chapter 2, with a theoretical explanation before/after every
code block.

## What's covered

| Section | Concepts | Dataset used |
|---|---|---|
| Sampling Distribution of a Statistic | data distribution vs. sampling distribution, Central Limit Theorem | `loans_income.csv` |
| The Bootstrap | resampling with replacement, bootstrap standard error | `loans_income.csv` |
| Confidence Intervals | percentile method, confidence level vs. width trade-off | `loans_income.csv` |

| Binomial Distribution | count of successes in n independent trials | simulated (n=20, p=0.1) |
| Poisson & Related | event counts, exponential (time-between-events), Weibull (time-to-failure) | simulated |

## Key takeaway

A single sample statistic never tells the whole story. The **sampling
distribution** concept — and its practical, computational cousin, the
**bootstrap** — let us quantify how much a statistic would vary across
different samples, without needing more data or complex formulas. That
uncertainty quantification is the foundation for every confidence interval
and hypothesis test in the chapters that follow.
